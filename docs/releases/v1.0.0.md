# g2rain-gateway-webflux v1.0.0

## 首次 GHCR 镜像发布

`g2rain-gateway-webflux` 是 G2rain（谷雨）开源智能体平台中的 Spring Cloud Gateway WebFlux 响应式统一入口实现。它交付动态路由、入口 API Key/JWT/DPoP/请求完整性与 API 权限校验、可信主体透传、响应调整和 OpenAPI 目录聚合；不拥有 IAM 的登录与 Token 签发、Basis 的路由与权限主数据、Infra 的错误消息主数据，也不单独交付平台的 SaaS、知识库、智能体或商业化能力。

本组件当前以 `webflux` 实现类型试点中央 `gateway-service 1.0.0-draft`，尚非正式 adopted 架构，也不能据此宣称已经完成环境集成验证。

## 构建与运行事实

- 项目版本：根 `pom.xml` 的 `revision` 为 `1.0.0`。
- 构建要求：JDK 25、Maven 3.9+；CI 使用 Temurin 25，运行 `mvn -B -ntp clean verify`。
- 关键框架：Spring Boot 4.1.2、Spring Cloud 2025.1.4、Spring Cloud Alibaba 2025.1.0.0。
- 运行时：`com.g2rain.gateway.Application`，默认端口 `8083`，默认 profile 为 `dev`。
- 容器基础镜像：`eclipse-temurin:25.0.4.1_1-jre`；最终镜像含 `/app/app.jar`，入口为 `java -jar /app/app.jar`。

## 发布顺序与 GHCR 权限

发布改动、工作流和本说明必须先进入 `main`，再在该提交创建 `v1.0.0`。工作流会拒绝非稳定 tag、非 `origin/main` 历史、缺失或空发布说明、以及与 Maven 版本不一致的 tag。

工作流使用 `GITHUB_TOKEN`（仅 `contents: read`、`packages: write`）登录 GHCR。首次推送成功后，维护者须在 GitHub Packages 的 **Package settings → Change visibility → Public** 设置公开包；若组织禁止变更，请联系管理员。已有同名包若返回 `denied`，应先检查 **Package settings → Actions access** 是否授予本仓写权限，并检查组织 Packages 策略。

## 镜像内容、安全与限制

镜像中的 Jar 打包了已跟踪的 `src/main/resources/application.yml`，该文件含 Nacos 开发默认用户名/密码，路径为 `/app/app.jar`。这不是 `.dockerignore` 可以治理的风险。生产 Token、DPoP 私钥、API Key、密码和 Nacos 凭据必须经环境变量、Nacos 配置中心或密钥管理服务注入，绝不可写入仓库或镜像。

已知限制：Nacos、Basis、Infra、Redis binder、IAM 契约与真实下游服务的端到端部署验证尚未完成；开发默认凭据、请求/响应日志脱敏和请求体资源上限仍属已登记风险。
