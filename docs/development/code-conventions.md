# 代码约定

- 使用响应式类型表达异步 I/O；请求链不使用阻塞式客户端或无界等待。
- 过滤器只完成单一入口职责，通过 `EdgePrincipalContext` 传递请求身份和校验结果。
- 新过滤器必须声明明确顺序、白名单键、前置依赖、跳过条件、错误码和测试。
- 客户端返回统一 `Result<T>` 时，通过公共异常转换器处理失败，不吞掉业务错误。
- 缓存和同步组件明确数据所有者、全量加载、create/update/delete 语义及并发策略。
- API、Header、JWT claim、DPoP、签名规范、路由 ID 和同步 dataSource 是跨仓库契约，变更时同步接口和兼容性文档。
- 日志默认最小化；任何 Header 或 body 记录都必须先做字段级脱敏和大小限制。
- 公共类、复杂响应式流程和安全判断使用说明“为什么”的 Javadoc，避免只翻译代码。
- 保持 `.editorconfig` 格式；提交前运行适用测试与静态检查。
